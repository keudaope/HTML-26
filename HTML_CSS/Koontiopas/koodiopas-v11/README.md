# Koodiopas v11 – oma kevyt GitHub Classroom

Uutta:

- kurssit
- kurssin ryhmät
- tehtävät
- template-repositoryn osoite
- repository-prefix
- opiskelijoiden GitHub-käyttäjänimet
- repository-suunnitelma
- repositoryjen olemassaolon tarkistus GitHubista

Esimerkki:

- prefix: `html-tehtava-1`
- GitHub-käyttäjä: `matti01`

Koodiopas odottaa repositorya:

`https://github.com/matti01/html-tehtava-1-matti01`

Tässä versiossa repositoryja ei vielä luoda GitHubiin automaattisesti. Se vaatii GitHub App- tai OAuth-yhteyden ja kirjoitusoikeuden.

Käynnistys:

```bash
npm install
npm start
```

Avaa:

`http://localhost:3000`

Seuraava vaihe: GitHub App / OAuth ja repositoryjen automaattinen luonti template-repositorysta.
