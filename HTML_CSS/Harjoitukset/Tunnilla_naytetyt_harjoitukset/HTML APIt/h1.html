Usein kysytyt kysymykset

Mikä on HTML?

HTML tarkoittaa HyperText Markup Language. Sillä määritellään verkkosivun rakenne ja sisältö.

Mihin CSS:ää käytetään?

CSS:llä määritellään verkkosivun ulkoasu, kuten värit, fontit, välit ja asettelu.

Mihin JavaScriptiä käytetään?

JavaScriptillä verkkosivulle voidaan lisätä ohjelmallista toimintaa ja interaktiivisuutta.
