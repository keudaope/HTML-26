Transformations ja transitions

TRANSFORMATIONS JA TRANSITIONS Liike ja muodonmuutos käyttöliittymässä – hallitusti, suorituskykyisesti ja saavutettavasti..button { transition: transform.2s ease, box-shadow.2s ease; }.button:hover { transform: translateY(-2px) scale(1.02); } ↔ Tavoite Osaat siirtää, kiertää, skaalata ja animoida tilamuutoksia CSS:llä hallitusti. ⚙ Miksi tärkeää? Pienet liikkeet selkeyttävät palautetta, hierarkiaa ja käyttöliittymän tiloja. ♿ Saavutettavuus Liike ei saa estää käyttöä. Huomioi prefers-reduced-motion. MUISTA TÄMÄ Transform muuttaa elementin visuaalista koordinaatistoa; transition pehmentää muutoksen ajan yli.

Transform ei työnnä ympäröivää sisältöä.

.card { transition: transform .25s ease, box-shadow .25s ease; }
.card:hover { transform: translateY(-.4rem); }

MIKÄ ON TRANSFORM?

transform muuttaa elementin visuaalista sijaintia, kokoa, kulmaa tai muotoa ilman tavallista layout-laskentaa. MOVE Siirrä translate() liikuttaa elementtiä X- ja Y-suunnassa. SIZE Skaalaa scale() kasvattaa tai pienentää. TURN Kierrä rotate() muuttaa kulmaa. SKEW Vinoita skew() kallistaa koordinaatistoa.
