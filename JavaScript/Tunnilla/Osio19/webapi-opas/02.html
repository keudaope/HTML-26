setTimeout ja clearTimeout

Mistä on kyse?

Ajastin tilaa yhden callbackin myöhemmäksi. 1000 ms on sekunti. Muu koodi jatkuu heti. Tunnisteella voi perua vielä odottavan tehtävän. Uusi ilmoitus kannattaa aloittaa peruuttamalla vanha ajastus.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Muuta viive viideksi sekunniksi.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const stop=document.getElementById("stop");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
let timer;
run.onclick=()=>{clearTimeout(timer);show('Ilmoitus näkyy');timer=setTimeout(()=>show('Ilmoitus poistui'),3000);};
stop.onclick=()=>{clearTimeout(timer);show('Suljettu');};
Demon HTML
<button id="run">Näytä ilmoitus 3 sekunniksi</button><button id="stop">Sulje heti</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
