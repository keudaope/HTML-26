performance.now ja Page Visibility

Mistä on kyse?

performance.now mittaa kulunutta aikaa monotonisella kellolla millisekunteina. document.hidden kertoo, onko sivu piilossa. visibilitychange auttaa tauottamaan turhaa työtä.

Kokeile itse

Vaihda välilehteä ja palaa.

Tulos näkyy tässä.

Harjoitus

Mittaa miljoonan kierroksen silmukka.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
run.onclick=()=>{const a=performance.now();let sum=0;for(let i=0;i<100000;i++)sum+=i;show(`${(performance.now()-a).toFixed(3)} ms, summa ${sum}`);};
document.addEventListener('visibilitychange',()=>log(document.hidden?'Piilossa':'Näkyvissä'));
Demon HTML
<button id="run">Mittaa silmukka</button><p>Vaihda välilehteä ja palaa.</p>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
