URL ja URLSearchParams

Mistä on kyse?

URL pilkkoo osoitteen osiin: origin, hostname, pathname, search ja hash. searchParams lukee ja muuttaa kyselyparametreja. set korvaa, append lisää, delete poistaa. Selain huolehtii erikoismerkkien koodauksesta.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Lisää page-parametri arvolla 2.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const field=document.getElementById("field");
const run=document.getElementById("run");
const change=document.getElementById("change");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
function inspect(change=false){try{const u=new URL(field.value,location.href);if(change){u.searchParams.set('q','JavaScript & CSS');u.searchParams.append('tag','web');u.searchParams.delete('page');field.value=u.href;}show(JSON.stringify({origin:u.origin,hostname:u.hostname,pathname:u.pathname,search:u.search,hash:u.hash,q:u.searchParams.get('q'),params:u.searchParams.toString()},null,2));}catch(e){show(e.message);}}
run.onclick=()=>inspect();change.onclick=()=>inspect(true);
Demon HTML
<label>URL <input id="field" value="https://example.com/kauppa?q=kirja#alku"></label><button id="run">Pura URL</button><button id="change">Muuta hakua</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
