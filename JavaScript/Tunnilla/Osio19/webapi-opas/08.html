ResizeObserver ja CSS-queryt

Mistä on kyse?

ResizeObserver seuraa elementin kokoa eikä vain selainikkunaa. CSS media query reagoi viewportiin, container query säiliön kokoon. Käytä CSS:ää ulkoasuun ja observeria, kun JavaScript tarvitsee mitat esimerkiksi kaavioon.

Kokeile itse

Muuttuva elementti
Tulos näkyy tässä.

Harjoitus

Tulosta myös elementin pinta-ala.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const size=document.getElementById("size");
const panel=document.getElementById("panel");
const stop=document.getElementById("stop");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
size.oninput=()=>panel.style.width=size.value+'px';
let ro;if('ResizeObserver' in window){ro=new ResizeObserver(entries=>{for(const e of entries)show(`${e.contentRect.width.toFixed(0)} × ${e.contentRect.height.toFixed(0)} px`);});ro.observe(panel);}else show('Ei tukea');
stop.onclick=()=>ro?.disconnect();
Demon HTML
<label>Leveys <input id="size" type="range" min="100" max="500" value="200"></label><div id="panel" class="card" style="width:200px;max-width:100%">Muuttuva elementti</div><button id="stop">Lopeta seuranta</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
