Clipboard API

Mistä on kyse?

writeText kopioi ja readText lukee leikepöydän. Molemmat palauttavat Promisen. await odottaa tulosta; try/catch käsittelee virheen. Käytä localhostia tai HTTPS:ää ja käynnistä toiminto painikkeesta.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Kopioi nykyinen URL tekstikentän sijaan.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const field=document.getElementById("field");
const run=document.getElementById("run");
const paste=document.getElementById("paste");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
run.onclick=async()=>{try{if(!navigator.clipboard)throw Error('Ei tukea');await navigator.clipboard.writeText(field.value);show('Kopioitu');}catch(e){show(e.message+' – kopioi käsin');}};
paste.onclick=async()=>{try{field.value=await navigator.clipboard.readText();show('Liitetty');}catch(e){show('Liitä käsin: '+e.message);}};
Demon HTML
<label>Teksti <input id="field" value="Hei maailma!"></label><button id="run">Kopioi</button><button id="paste">Liitä</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
