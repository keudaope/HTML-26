Harjoitus: lazy reveal

Mistä on kyse?

Tavoite: kuusi korttia, 25 % näkyvyysraja, seuranta loppuu ensimmäiseen havaintoon. Vähennetyn liikkeen käyttäjälle sisältö näkyy heti.

Harjoitus

Toteuta ensin kuusi korttia ja lisää observer.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const area=document.getElementById("area");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
const cards=area.querySelectorAll('.card');if(matchMedia('(prefers-reduced-motion: reduce)').matches||!('IntersectionObserver' in window)){cards.forEach(c=>c.classList.add('visible'));}else{const o=new IntersectionObserver(es=>{for(const e of es){if(e.intersectionRatio>=.25){e.target.classList.add('visible');o.unobserve(e.target);}}},{root:area,threshold:.25});cards.forEach(c=>o.observe(c));window.addEventListener('pagehide',()=>o.disconnect());}
Demon HTML
<div id="area" class="scrollbox"><div class="card">Kortti 1</div><div class="card">Kortti 2</div><div class="card">Kortti 3</div><div class="card">Kortti 4</div><div class="card">Kortti 5</div><div class="card">Kortti 6</div></div>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
