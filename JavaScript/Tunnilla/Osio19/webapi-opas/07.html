IntersectionObserver, unobserve ja disconnect

Mistä on kyse?

Observer on kuin ovivahti: selain ilmoittaa, kun kortti ylittää näkyvyysrajan. Root on tarkkailualue, threshold 0.25 tarkoittaa 25 prosenttia. isIntersecting kertoo leikkauksesta, intersectionRatio sen osuudesta. unobserve lopettaa yhden kortin, disconnect kaikki.

Harjoitus

Muuta näkyvyysraja 50 prosenttiin sekä asetuksessa että ehdossa.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const stop=document.getElementById("stop");
const area=document.getElementById("area");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
let observer;
run.onclick=()=>{observer?.disconnect();if(!('IntersectionObserver' in window)){show('Ei tukea');return;}observer=new IntersectionObserver(entries=>{for(const entry of entries){if(entry.isIntersecting&&entry.intersectionRatio>=0.25){entry.target.classList.add('visible');log(entry.target.textContent+' näkyy');observer.unobserve(entry.target);}}},{root:area,threshold:0.25});area.querySelectorAll('.card').forEach(c=>{c.classList.remove('visible');observer.observe(c);});};
stop.onclick=()=>observer?.disconnect();
Demon HTML
<button id="run">Aloita seuranta</button><button id="stop">Lopeta</button><div id="area" class="scrollbox"><div class="card">Kortti 1</div><div class="card">Kortti 2</div><div class="card">Kortti 3</div><div class="card">Kortti 4</div><div class="card">Kortti 5</div><div class="card">Kortti 6</div></div>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
