Feature detection, käyttöoikeudet ja DevTools

Mistä on kyse?

Progressive enhancement tarkoittaa toimivaa perusratkaisua ja tuetuissa selaimissa parempaa ominaisuutta. Tarkista tuki, turvallinen konteksti, lupa, käyttäjän toiminto, Promise-virhe ja resurssin lopetus. Console näyttää virheitä; Application näyttää sovellustilaa; Sensors ja Rendering voivat emuloida ympäristöä.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Avaa Console ja vertaa tuloksia. Mikä olisi fallback puuttuvalle Clipboard API:lle?

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
run.onclick=()=>show(JSON.stringify({secureContext:isSecureContext,clipboard:!!navigator.clipboard,share:!!navigator.share,geolocation:!!navigator.geolocation,observer:'IntersectionObserver' in window,fullscreen:!!document.documentElement.requestFullscreen},null,2));
Demon HTML
<button id="run">Tarkista ominaisuudet</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
