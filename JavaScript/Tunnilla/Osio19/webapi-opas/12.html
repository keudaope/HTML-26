Navigator ja online/offline

Mistä on kyse?

navigator kertoo ympäristön ominaisuuksia. onLine on karkea yhteystila, ei takuu palvelimen saavutettavuudesta. online ja offline ovat window-tapahtumia. Tarkista ominaisuuden olemassaolo selaimen nimen sijaan.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Kokeile DevToolsin Offline-tilaa ja palauta yhteys.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
function render(){show(JSON.stringify({language:navigator.language,languages:navigator.languages,onLine:navigator.onLine,clipboard:'clipboard' in navigator,share:'share' in navigator},null,2));}
run.onclick=render;window.addEventListener('online',render);window.addEventListener('offline',render);render();
Demon HTML
<button id="run">Tutki selainta</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
