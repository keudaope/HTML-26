setInterval ja clearInterval

Mistä on kyse?

Interval toistaa callbackia, kunnes se perutaan. Se ei ole tarkka kello: kuormitus ja taustavälilehti voivat viivästyttää kutsuja. Timeout suorittaa kerran, interval toistuvasti.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Pysäytä laskuri automaattisesti kohdassa 10.

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const stop=document.getElementById("stop");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
let timer, n=0;
run.onclick=()=>{clearInterval(timer);n=0;show(n);timer=setInterval(()=>{show(++n);if(n===5)clearInterval(timer);},1000);};
stop.onclick=()=>clearInterval(timer);
Demon HTML
<button id="run">Aloita</button><button id="stop">Pysäytä</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
