History API ja Location

Mistä on kyse?

pushState lisää historiatietueen, replaceState korvaa nykyisen. Kumpikaan ei renderöi näkymää: oma render-funktio tekee sen. popstate reagoi takaisin/eteenpäin. location.href kertoo osoitteen; assign navigoi, replace korvaa nykyisen historiatietueen ja reload lataa uudelleen. SPA:n suorat reitit vaativat usein palvelimen fallbackin.

Kokeile itse

Tulos näkyy tässä.

Harjoitus

Kokeile A, B, C ja selaimen takaisin-painiketta. Miksi B korvautuu?

Avaa toimiva mallikoodi (JavaScript)
// Haetaan demon HTML-elementit.
const run=document.getElementById("run");
const next=document.getElementById("next");
const replace=document.getElementById("replace");
const reload=document.getElementById("reload");
const result=document.querySelector("#result");
// Näytä tulos sivulla, ei vain konsolissa.
function show(value){result.textContent=String(value);}
function log(value){result.textContent+= "\n"+value;}
function render(){show('Näkymä: '+(new URL(location.href).searchParams.get('view')||'alku')+'\n'+location.href);}
function navigate(view,replace=false){try{const u=new URL(location.href);u.searchParams.set('view',view);history[replace?'replaceState':'pushState']({view},'',u);render();}catch(e){show('Käytä localhostia: '+e.message);}}
run.onclick=()=>navigate('A');next.onclick=()=>navigate('B');replace.onclick=()=>navigate('C',true);reload.onclick=()=>location.reload();window.addEventListener('popstate',render);render();
Demon HTML
<button id="run">Näkymä A</button><button id="next">Näkymä B</button><button id="replace">Korvaa näkymällä C</button><button id="reload">Lataa uudelleen</button>

Muista: tarkista Console, jos toiminto ei käynnisty. Varmista elementin id, API:n tuki ja tarvittaessa käyttöoikeus. Älä rekisteröi kuuntelijaa toistuvasti.
