Opettajan vastausversio: saavutettavuusauditointi

Tämä vastausversio perustuu opiskelijoille jaettuun saavutettavuus-harjoitus.html-sivuun. Alla on 15 tarkoituksellista ongelmaa, niiden vaikutus ja suositeltu korjaus.

1. lang="fi" puuttuu html-elementistä

Ongelma: Dokumentin pääkieltä ei ole määritelty.

Kenelle haittaa: Erityisesti ruudunlukijan käyttäjille, koska puhesynteesi voi käyttää väärää ääntämistä.

Korjaus:

<html lang="fi">

2. Navigaation linkkitekstit ovat epäselviä

Linkit kuten Klikkaa tästä, Lue lisää ja Siirry eivät kerro kohdetta ilman ympäröivää kontekstia.

Kenelle haittaa: Ruudunlukijan käyttäjille ja käyttäjille, jotka selaavat linkkilistaa.

Korjaus:

<a href="#ohjelma">Päivän ohjelma</a>
<a href="#kouluttajat">Kouluttajat</a>
<a href="#ilmoittautuminen">Ilmoittautuminen</a>

3. Otsikkohierarkia hyppää tasolta h2 tasolle h4

Ohjelmakorteissa käytetään suoraan h4-otsikoita h2-otsikon alla.

Kenelle haittaa: Käyttäjille, jotka navigoivat otsikoiden avulla.

Korjaus: Käytä esimerkiksi h3-otsikoita.

4. Div-elementti toimii painikkeena

<div class="fake-button" onclick="..."> näyttää painikkeelta, mutta ei ole näppäimistöllä luonnostaan käytettävä eikä sillä ole oikeaa roolia.

Kenelle haittaa: Näppäimistö- ja ruudunlukijakäyttäjille.

Korjaus:

<button type="button" onclick="...">Ilmoittaudu</button>

5. Fokusindikaattorit on poistettu CSS:llä

CSS sisältää outline: none linkeille, painikkeille ja lomakekentille.

Kenelle haittaa: Näppäimistökäyttäjille, koska aktiivista kohdetta ei näe.

Korjaus: Älä poista fokusta ilman selkeää korvaavaa tyyliä.

:focus-visible {
  outline: 3px solid #7a3fc1;
  outline-offset: 3px;
}

6. Tekstin kontrasti on liian heikko

.muted { color: #b9b9b9; } vaalealla taustalla tekee tekstistä vaikealukuisen.

Kenelle haittaa: Heikkonäköisille ja käyttäjille huonoissa näyttöolosuhteissa.

Korjaus: Käytä tummempaa tekstiväriä.

7. Ensimmäiseltä kuvalta puuttuu alt-teksti

img-elementillä ei ole lainkaan alt-attribuuttia.

Kenelle haittaa: Ruudunlukijan käyttäjille.

Korjaus: Jos kuva välittää sisältöä, kirjoita kuvaava alt-teksti.

<img src="..." alt="Anna Aalto, HTML-kouluttaja">

8. Toisen kuvan alt-teksti on tiedostonimi

alt="kuva2.jpg" ei kuvaa kuvan sisältöä.

Korjaus: Kuvaa olennainen sisältö, esimerkiksi henkilön nimi tai rooli.

9. Koristekuvalla on tarpeettoman pitkä alt-teksti

Kolmas kuva on selvästi koristeellinen, mutta sille annetaan kuvaileva alt-teksti.

Kenelle haittaa: Ruudunlukijan käyttäjille turhana informaationa.

Korjaus:

<img src="..." alt="">

10. “Miksi osallistua?” on div, ei otsikko

Visuaalisesti otsikon näköinen teksti on tehty div-elementillä.

Kenelle haittaa: Käyttäjille, jotka navigoivat otsikoiden avulla.

Korjaus:

<h2>Miksi osallistua?</h2>

11. Taulukon ensimmäinen rivi ei käytä th-elementtejä

Taulukon otsikot Aika, Aihe, Tila on merkitty tavallisina td-soluina.

Kenelle haittaa: Ruudunlukijan käyttäjille, koska sarakkeiden suhteet eivät välity yhtä hyvin.

Korjaus:

<tr>
  <th scope="col">Aika</th>
  <th scope="col">Aihe</th>
  <th scope="col">Tila</th>
</tr>

12. Lomakekentiltä puuttuvat kunnolliset label-elementit

Nimi on tavallista tekstiä, sähköpostikenttä luottaa placeholderiin ja textarea käyttää erillistä p-elementtiä.

Kenelle haittaa: Ruudunlukijan käyttäjille ja kaikille, kun placeholder katoaa kirjoitettaessa.

Korjaus:

<label for="nimi">Nimi</label>
<input id="nimi" name="nimi" type="text">

<label for="email">Sähköpostiosoite</label>
<input id="email" name="email" type="email">

13. Checkboxin teksti ei ole label-elementti

Checkboxilla on id="ehdot", mutta näkyvä teksti ei ole siihen sidottu label.

Korjaus:

<input type="checkbox" id="ehdot" name="ehdot">
<label for="ehdot">Hyväksyn tapahtuman ehdot</label>

14. Iframelta puuttuu title

iframe-elementtiä ei ole nimetty saavutettavasti.

Kenelle haittaa: Ruudunlukijan käyttäjille, jotka eivät muuten tiedä mitä upotus sisältää.

Korjaus:

<iframe title="Koodikoulun opiskelijapäivän esittelyvideo" ...>

15. Sama id-arvo esiintyy kahdesti

Sekä otsikolla että kappaleella on id="lisatiedot".

Ongelma: id:n pitäisi olla yksilöllinen dokumentissa.

Vaikutus: Ankkurilinkit, ARIA-viittaukset, CSS ja JavaScript voivat kohdistua väärin tai epäselvästi.

Korjaus: Käytä yksilöllisiä id-arvoja tai poista tarpeeton id.

Korjattu mallikoodi: keskeiset rakenteet

<!DOCTYPE html>
<html lang="fi">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Koodikoulun opiskelijapäivä</title>
</head>
<body>

<header>
  <h1>Koodikoulun opiskelijapäivä</h1>
</header>

<nav aria-label="Päänavigaatio">
  <a href="#ohjelma">Päivän ohjelma</a>
  <a href="#kouluttajat">Kouluttajat</a>
  <a href="#ilmoittautuminen">Ilmoittautuminen</a>
</nav>

<main>
  <section id="ohjelma">
    <h2>Päivän ohjelma</h2>
    <article>
      <h3>HTML käytännössä</h3>
      <p>...</p>
      <button type="button">Ilmoittaudu</button>
    </article>
  </section>

  <section>
    <h2>Kurssiaikataulu</h2>
    <table>
      <tr>
        <th scope="col">Aika</th>
        <th scope="col">Aihe</th>
        <th scope="col">Tila</th>
      </tr>
      ...
    </table>
  </section>

  <section id="ilmoittautuminen">
    <h2>Ilmoittaudu tapahtumaan</h2>
    <form>
      <label for="nimi">Nimi</label>
      <input id="nimi" name="nimi" type="text">

      <label for="email">Sähköpostiosoite</label>
      <input id="email" name="email" type="email">

      <input type="checkbox" id="ehdot" name="ehdot">
      <label for="ehdot">Hyväksyn tapahtuman ehdot</label>
    </form>
  </section>

  <iframe
    title="Koodikoulun opiskelijapäivän esittelyvideo"
    ...>
  </iframe>
</main>

</body>
</html>

Opettajan arviointivinkki

TasoOsaaminen
PerustasoLöytää 5–7 ongelmaa ja osaa korjata tärkeimmät rakenteelliset puutteet.
HyväLöytää vähintään 10 ongelmaa ja perustelee vaikutuksen käyttäjälle.
ErinomainenLöytää lähes kaikki ongelmat, testaa näppäimistöllä ja DevToolsilla sekä perustelee korjaukset saavutettavuuden näkökulmasta.
