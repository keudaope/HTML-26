Dia 7

Web-fontit ja @font-face

Koska esimerkkitiedostoon ei liitetä ulkoista fonttia, tämä teksti käyttää turvallista fallbackia.
@font-face {
  font-family: "Course Sans";
  src: url("course.woff2") format("woff2");
  font-weight: 100 900;
  font-display: swap;
}

Käytä vain fonttia, jonka verkkokäyttö- ja jakeluoikeus sinulla on.

Dia 8

Dia 30

Harjoitus 1: typografinen järjestelmä

CSS-KURSSI • 28.9.2026

Typografia tekee sisällöstä ymmärrettävää

Johdanto käyttää samaa leipätekstin kokoa ja rivirytmiä kuin muu artikkeli.

Johdonmukainen asteikko

Rajattu asteikko vähentää sattumanvaraisia kokoja. Esimerkiksi font-size: var(--text-md) käyttää yhteistä tokenia.

Linkit ja koodi

Lisätietoa löytyy typografian ohjeesta. Koodin fontti on monospace.

Näytä tehtävän 1 CSS-ratkaisu
:root {
  --text-sm: .875rem;
  --text-body: 1rem;
  --text-h3: 1.5rem;
  --text-h2: 2rem;
  --leading-body: 1.65;
}
article { max-width: 65ch; margin-inline: auto; }
h1 { font-size: clamp(2.4rem, 6vw, 4.5rem); }
h2 { font-size: var(--text-h2); }
h3 { font-size: var(--text-h3); }
p { font-size: var(--text-body); line-height: var(--leading-body); }
small { font-size: var(--text-sm); }
a { text-underline-offset: .18em; }
code { font: .9em ui-monospace, monospace; }

Harjoitus 2 ja virheenetsintä

UUTINEN

Pidempi uutisotsikko säilyy luettavana myös kapeassa näkymässä

Kortilla ei ole kiinteää korkeutta, joten pitkä teksti ja 200 prosentin zoomaus kasvattavat korttia.

Lue koko uutinen
Ratkaisu ja pikavisan vastaukset
.card {
  width: min(100%, 38rem);
  min-height: 0;
  padding: 1.25rem;
}
.card h2 {
  font-size: clamp(1.5rem, 6vw, 2.5rem);
}
.card a {
  text-decoration: underline;
  text-decoration-thickness: .1em;
  text-underline-offset: .18em;
}

Miksi kiinteä height aiheutti ongelman?
Sisällön määrä, kielen sanapituudet, fallback-fontin mittasuhteet ja käyttäjän zoomaus voivat kasvattaa tekstin tarvitsemaa korkeutta. Kiinteä 220 px laatikko ei kasva mukana, joten sisältö leikkautuu tai ylivuotaa.

rem ja em
rem perustuu juurielementin laskettuun fonttikokoon, joten se sopii ennustettavaan sivunlaajuiseen asteikkoon. em perustuu font-size-ominaisuudessa vanhemman fonttikokoon ja muissa ominaisuuksissa yleensä elementin omaan fonttikokoon. Se sopii komponentin sisäisiin suhteisiin, mutta sisäkkäisyys voi kerrata arvoja.

Miksi yksikötön line-height?
Esimerkiksi line-height: 1.6 kertoo kertoimen. Se skaalautuu automaattisesti elementin oman fonttikoon mukana ja periytyy turvallisemmin kuin kiinteä pikseli- tai rem-rivikorkeus.
